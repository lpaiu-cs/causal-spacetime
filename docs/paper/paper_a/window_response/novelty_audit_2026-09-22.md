# Diamond 결과의 식 단위 차별성 검토

검토일: 2026-09-22. 대상: 2026-09-21 보완연구의 `p_D`, `zeta_D`와 부피 유도.
기존 확인자료 이후의 문헌 비교와 수학적 따름정리다. 새 사전등록이나 확인실험이 아니다.

**결론:** 일반적인 부분구간 적분법이나 공유점 분산 구조를 새 방법이라고 주장할 수
없다. 남는 기여 후보는 지정한 진공 평면파에서의 명시적 평균·공분산 계수,
평탄 차원 보정의 편향 계수, 그리고 문헌 최종 부피식과의 재현 가능한 불일치다.
마지막 항목은 외부 판정이 없는 좁은 수학적 비교이며, 일반 진공 부피 공식의
정정을 완성했다는 뜻이 아니다. 게재 가능성이 높아졌다고 정량 판정하지 않는다.

## 1. 가까운 선행식과의 경계

| 비교 대상 | 이미 있는 것 | 이 원고에서 남는 계산 |
|---|---|---|
| [Roy–Sinha–Surya (2013)](https://arxiv.org/html/1212.0631), Eqs. (5)–(12), (16), (62)–(66) | 중첩 부피로 chain 평균 계산, 선도 Ricci 항, 공유점을 가진 chain의 요동 | 특정 Ricci-flat 평면파의 이차 계수와 유한 A 적분 평가 |
| [Kambor–Nomaan (2020)](https://arxiv.org/html/2007.03835), Eqs. (3)–(7), §2–3 | chain 기반 곡률·차원 추정의 수치적 적용과 안정성 | 이 진공 family에서 평탄 차원 보정의 명시적 편향 |
| [Wang (2019), arXiv v2](https://arxiv.org/pdf/1904.01034v2), Eqs. (1), (74), (76), (79) | 전기·자기 Weyl 분해와 진공 다이아몬드 부피의 곡률 제곱 전개 | 아래 정규화로 최종 계수와 직접 대조; 중간식 재적분과 독립 좌표 계산 |
| Hoeffding U-statistic 분산식 | 쌍의 공유점 공분산과 N 의존성 | `zeta_D` 자체의 구체적 평면파 평가 |

두 독립점의 관계 확률을 `p`, 한 점의 조건부 관계 확률을 `q(X)`라 하면,
다이아몬드에서 `q=(V_past+V_future)/V`다. `p=E[q]`, `E[q²]`의 구성 자체는
위 chain·겹침 적분의 재표현이다. 일반 방법의 최초성 주장을 원고에서 제거했다.

정규화도 맞췄다. Roy의 Poisson 규약에서 `E[C2]/E[C1]²`는 우리의 무순서 쌍
관계 비율의 절반이다. 우리는 고정 N 조건부 표본을 쓰므로 분산에는
`zeta=E[q²]−p²`가 들어간다. 이 차이를 새로운 물리 효과로 해석하지 않는다.

2026년의 Hasse/Weyl·표본복잡도·graph-observable 연구와의 경계는
[전날 검토](../novelty_audit_2026-09-21.md)에 유지했다. 추가 검색에는
`causal plane wave ordering fraction`, `Myrheim plane wave`,
`causal set Weyl chain ordering probability`, `causal diamond plane wave volume`,
`Wang Geometry of small causal diamonds erratum`, `1904.01034 correction volume`을
사용했다. 이번 범위에서는 아래 명시적 계수의 동일한 선행 결과나 해당 불일치의
공개 정정문을 찾지 못했다. **검색 미발견은 최초성이나 정정문 부재의 증명이 아니다.**

## 2. 계수가 제공하는 해석을 추가했다

기존 동결식은 그대로다.

```text
p_D    = 1/10  − (23/75600) A² + O(A⁴)
zeta_D = 1/100 − (211/4158000) A² + O(A⁴)
```

축 방향 단위 시간벡터 `U=(∂u−∂v)/√2`에 대해 직접 곡률을 수축하면
`E=diag(−A/2,A/2,0)`이다. `T=√2`, `kappa=E_ij E^ij T⁴=2A²`로 바꾸면
평균의 계수는 `−23/151200`, 공분산 계수는 `−211/8316000`이다.
이것은 정한 다이아몬드 방향에 상대적인 조석 강도다. 일반 진공에서 여러 Weyl
불변량의 계수를 각각 분리한 결과는 아니다.

평탄 Myrheim–Meyer 관계는
`F(d)=Gamma(d+1)Gamma(d/2)/(2Gamma(3d/2))`이며 `F'(4)=−101/1200`이다.
`F(d_pop)=p_D`를 풀면 다음의 따름정리가 나온다.

```text
d_pop = 4 + (23/6363) A² + O(A⁴)
```

따라서 실제 차원이 4인 진공에서도 평탄 보정을 적용한 모집단 차원값은 증가한다.
이를 curvature bias 일반 개념의 발견으로 주장하지 않고, 이 family의 검산용
계수로 제시했다. `d_pop`은 `E[F^(-1)(f_N)]`가 아니다. 유한 표본 역함수에는
별도 비선형 편향이 있다. 이 따름정리의 새 Monte Carlo 확인을 수행하지 않았다.

## 3. 부피 계수의 불일치

같은 물리적 대상과 표기를 사용했다.

```text
ds² = 2du dv + A(x²−y²)du² + dx² + dy²
P=(0,1/2,0,0), Q=(1,−1/2,0,0)
d=4, T=√2, l=T/2=1/√2
E²=A²/2, H²=A², D²=2A²
Ricci=0, covariant derivative of Riemann=0
```

이 표기의 `V(A)/V(0)=1+c A²+…`에서:

| 계산 경로 | c |
|---|---:|
| 정확 Brinkmann 단면 적분의 전개 | `1/252 = 0.003968253968…` |
| 지수사상으로 얻은 Riemann 정상좌표 경계·Jacobian 적분 | `1/252` |
| Wang v2 Eqs. (74),(76)를 위 곡률로 특수화한 재적분 | `1/252` |
| Wang v2의 최종 Eq. (79)에 같은 값을 대입 | `43/9450 = 0.004550264550…` |

차이는 `11/18900`이다. 최종식의 **곡률 보정 계수**가 직접 계산값보다
`86/75`배 크다. 전체 부피가 14.7% 다르다는 뜻이 아니다.

단순 HTML 수식 변환 문제인지 확인하기 위해 arXiv v2 PDF의 12쪽을 직접 렌더링해
Eq. (79)를 확인했다. [arXiv 메타데이터](https://arxiv.org/abs/1904.01034)는
2019-08-22 v2를 published version으로 표시한다. 출판사 조판본 전체는 이번
접근에서 구독 장벽으로 읽지 못했으므로, 비교 대상을 **arXiv v2의 명시된 식**으로
한정한다. [APS 논문 페이지](https://journals.aps.org/prd/abstract/10.1103/PhysRevD.100.064020)에서
서지사항을 확인했다.

읽은 PDF의 SHA256:
`4f682665eaceb3ae5f6ce643d85b834a4ab6d7810068fc830984c9432ce59dc1`.
저작권이 있는 외부 PDF를 배포 manifest나 Git bundle에 포함하지 않았다.

## 4. 독립 좌표 계산과 재현

원고 부록 A에 지수사상, 부피 Jacobian, null 경계의 이차 전개와 적분을 실었다.
중간점의 정상좌표에서 `s=(t+z)/√2`로 두면 Jacobian은 정확히
`sinh(√A s) sin(√A s)/(A s²)`이다. 경계의 이동까지 함께 적분하여
`V=2πl⁴/3 [1+A²l⁴/63+O(A⁴l⁸)]`를 얻는다.

[check_diamond_geometry.py](check_diamond_geometry.py)는 실험 코드를 import하지
않고 다음을 재계산한다.

- 원래 metric의 Christoffel·Riemann·Ricci와 `∇R=0`.
- 직교 tetrad의 `E²,H²,D²`, Wang 최종식 대입.
- 정상좌표 Jacobian·null 경계 잔차·부피 적분.
- Wang 중간식의 각도·반지름·시간 적분.
- 60자리 계산에서 작은 A의 정확 단면 적분, 차원 보정 역함수의 계수.

출력은 [geometry_audit.json](geometry_audit.json)에 저장했다. 실행한 script의
LF-normalized SHA256과 Python/SymPy/mpmath 버전도 포함한다.
실행: `python docs/paper/paper_a/window_response/check_diamond_geometry.py`.
SymPy 1.14.0, mpmath 1.3.0에서 검산했다. 기존 확인 표본을 읽거나 바꾸지 않는다.

이 검산은 같은 AI가 작성하고 확인한 계산이다. 독립 좌표·계산 경로와
독립된 사람의 검토는 다르다. 원고에서 이 차이를 명시했다.

## 5. 원고 반영과 남은 판단

제목·초록·서론·결과 순서를 diamond 평균·공분산과 그 의미 중심으로 바꿨다.
사각 영역은 관측 영역에 따라 응답이 달라지는 비교 사례로 배치했다.
원고에는 차원 보정 편향, 부피 불일치와 독립 정상좌표 부록을 추가했다.
51,200개 확인 자료, 검정 기준, 8개 예측, 결과와 이전 freeze는 수정하지 않았다.

이전보다 기여를 구체적으로 심사할 수 있게 됐다. 다만 **명시적 특수 경우의
계산이 해당 학술지에 충분히 중요한지**, 그리고 **부피 비교가 외부 수학적 검토에서도
유지되는지**는 남아 있다. 이를 접수 가능성의 높은 확률로 바꾸어 말하지 않는다.
다음 검토의 가장 중요한 대상은 부록 A와 Wang Eq. (79)의 비교다.
외부 연락·새 투고·공개 업로드는 이번 작업에 포함하지 않았다.
