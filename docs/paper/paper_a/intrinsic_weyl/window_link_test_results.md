## 방법 요약

프로토콜 Sect. 3–5를 그대로 따랐다. 동결 시험과 달라진 것은 창의 위치,
스텐실, 반사실 판독, 판정, 중단 규칙뿐이다.

1. 창 `w = 0..4`는 세계선 위 고유시간 오프셋 −2/3, −1/3, 0, 1/3, 2/3(꼭짓점
   간격 단위)에 있다. 각 창은 독립 산포다. 선택 사건 4096개와 측정 사건
   `2^25`개를 뽑는다.
2. 다음은 동결 시험과 같다.
   - 공유 랜드마크 규칙과 시계 규칙
   - 5차 역추정기와 블라인드 경계
   - O(3) Procrustes 연결(바깥으로 사슬), 연결당 공유 랜드마크 8개 이상
   - 중심 창에서의 별칭 사상과 최소 노름 연산자 `B`
3. 스텐실은 `h = 1/3`의 5점 2차다. `W_0 = I + 22.5B + 486B²`,
   `W_(±h) = −12B − 324B²`, `W_(±2h) = 0.75B + 81B²`이다.
4. 보정을 저장한 뒤 평가 단계가 세 가지를 한다.
   - 주 판독을 저장된 가중치, 연결, 적합에서 다시 계산한다. 차이가 `1e-9`를
     넘으면 실행을 멈춘다.
   - 반사실 판독과 옆 창의 연결 판독을 더한다.
   - 오라클 틀은 보정을 저장한 뒤에만 구한다.
5. 판독은 `a_r = <c, Σ_s W_s M(R_s) c_s>/<c, c>`다. 내적은 완전 조석
   내적이고, `c`는 중심 창 추정 틀에 놓은 참값이다. 96반복 평균과 95% 양측
   t 구간(자유도 95)으로 판정한다.

- **실행 상수와 원천 파일.**
  - 실행 상수 15개를 실행 기록이 아니라 프로토콜과 견주었고, 모두 같다.

    같다. 검사 스크립트가 돈 체크아웃의 같은 파일과도 같다. 그래서 재적합도
    스탬프 코드로 돌았다.

- 검사 스크립트는 실행기와 세 가지를 공유한다.

  - `intrinsic_weyl_window_study`의 별칭 사상, 백색화, 최소 노름 연산자
- 연산자 `B`는 시계를 남긴 반복 0과 48에서만 다시 구했다. 나머지 94개 반복은

  - `B`는 중심 창 항(1.20)과 옆 창 가중치를 함께 정한다.
  - 참 방향으로 `B`가 단위만큼 바뀌면 판독은 약 10만큼 움직인다.
  - 그 함수들의 결함은 이 검사로 잡히지 않는다. 동결 시험의 기록도 같은
    한계를 적었다.
