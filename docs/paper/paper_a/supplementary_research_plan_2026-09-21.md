## 1. 결정: 논문의 중심 질문을 하나로 줄인다

권고하는 질문은 다음이다.

> 유한한 인과집합에서 관계 비율로 진공 평면파를 판별할 때, 관측 영역의
> 대칭성과 표본 크기가 검출력을 어떻게 결정하는가? 그 효과를 계산해서
> 보지 않은 조건의 단일 인과집합 판별 성능까지 예측할 수 있는가?

목표 산출물은 **관측 프로토콜을 명시한 곡률 응답식과 검출력 예측의 독립 검증**이다.
표본을 더 모아 기존 강한 운영점의 AUC를 높이는 작업은 하지 않는다.
기존의 광범위한 재구성 사다리는 배경·검증 도구로 사용한다.
Schwarzschild 질량 사다리를 더 늘리는 것은 이번 주 연구에서 제외한다.

잠정 영문 제목은 *Observation-window dependence and finite-sample detectability
of vacuum curvature in causal orders*이다. 제목의 범위는 결과에 맞춰 더 좁힐 수 있다.
새 정리, 최초 Weyl 검출, 보편적인 곡률 복원, 시공간의 창발을 선결 주장하지 않는다.

이 경로를 고른 이유는 기존 평면파 술어가 빠르고, 탐색 자료가 이미 있으며,
현재 원고의 강한 분리가 왜 생기는지를 설명하는 연구로 이어질 수 있기 때문이다.
다만 **대칭성의 관찰 자체는 이미 저장소에 있다. 이것만으로 새 논문을 만들 수는 없다.**
아래 G0에서 선행연구와 구별되는 정량적 질문이 남지 않으면 대규모 계산을 시작하지 않는다.

## 4. 이론 작업: 무엇을 증명하고 무엇을 예측할 것인가

### 4.1 물리량과 관측 규약을 먼저 고정한다

기존 코드의 계량은 `ds² = 2 du dv + A(x²-y²) du² + dx² + dy²`, `A=w²`다.
중심의 단위 시간꼴 관측자와 transverse 축, 관측 길이를 함께 명시한다.
고정된 그 규약에서 `lambda = A (Delta u)²`, `a = sqrt(lambda)`를 사용한다.
lambda는 그 규약의 무차원 조석 세기 매개변수이며 일반적인 곡률 스칼라가 아니다.
축 교환으로 구현하는 부호 있는 A도 이론 유도에서만 명확히 정의한다.
코드의 w에 음수를 넣는 것으로 음의 A를 구현했다고 간주하지 않는다.

주 영역은 `lambda <= 2`, 따라서 `a <= sqrt(2) < pi`로 제안한다.
정확한 술어의 첫 conjugate point 이전이라는 조건을 모든 쌍에서 확인한다.
좌표 정규화만 바꾼 경우와 관측자/관측 영역을 물리적으로 바꾼 경우를 구분한다.
Type N에서는 `C_abcd C^abcd`가 0일 수 있으므로 이를 세기 축으로 사용하지 않는다.
Ricci가 0이라는 이유로 곡률 전체가 0이라는 null을 구성하지 않는다.

### 4.2 응답의 대칭성과 계수

`f_N = C(N,2)^(-1) sum_{i<j} h(X_i,X_j)`로 둔다.
h는 어느 방향으로든 두 사건이 인과적으로 관련되어 있으면 1인 대칭 kernel이다.
입력은 한 poset의 관계와 N이며 좌표, 곡률 label, 다른 팔의 poset은 받지 않는다.
영역 R의 균일한 물리적 부피 표본에 대해 `p_R(lambda)=E[f_N]`를 정의한다.

이 입력 제한은 **f의 계산 단계**에 관한 것이다. 관측자·box·diamond tips를 정하고
표본을 모으는 절차는 알려진 연속체 규약을 사용한다. 임의의 poset에서 영역까지
순서만으로 찾아내는 알고리즘이라는 뜻은 아니다. 기존 Class C의 coordinate guard를
재사용하면 그 추가 입력을 별도로 표시한다.

해야 할 유도는 다음과 같다.

1. x/y와 부호 있는 A를 함께 교환할 때의 정확한 관계를 쓴다.
   교환 대칭인 영역에서는 응답이 A에 대해 짝함수임을 보인다.
   미분 가능성까지 성립할 때 1차 항이 사라진다. 짝함수라는 사실만으로
   비해석적인 `|A|` 항까지 배제했다고 주장하지 않는다.
2. 고정된 영역에서 `p_R(lambda)-p_R(0)`의 첫 비영 계수를 계산한다.
   causal cone 경계에서 indicator를 미분하는 정당화와 나머지 오차를 포함한다.
   비대칭 영역의 1차 계수가 비영이라는 것은 허용되는 가능성이지 선결 사실이 아니다.
3. intrinsic diamond는 영역 자체와 정규화 부피도 A에 따라 변한다.
   경계 이동과 정규화의 미분을 빼먹지 않는다. 박스의 유도를 그대로 가져오지 않는다.
4. P3-E의 경험적 기울기를 재인용하는 데서 끝내지 않고, 계수 또는
   구간별 정량 예측과 유효 범위를 제출한다. 해석적인 나머지 bound를 못 얻으면
   수치 오차와 관측 범위가 명시된 수치 예측으로 등급을 낮춘다.

이를 통해 비대칭 영역의 1차 민감도와 대칭 영역의 2차 민감도가 실제로 성립하는지,
또 어디서 근사가 깨지는지 판단한다. 새 확인 데이터로 fit 범위를 고르지 않는다.

### 4.3 잡음과 검출력: 쌍 개수를 독립 표본 수로 쓰지 않는다

고정 N의 iid 점들에 대해 `zeta_R = Cov(h(X1,X2), h(X1,X3))`라 두면
공유 index를 세어서 다음의 정확한 항등식을 얻는다.

```text
Var(f_N) = 2 p_R(1-p_R) / [N(N-1)]
         + 4 (N-2) zeta_R / [N(N-1)].
```

이는 새로운 통계 정리가 아니다. 이 모형의 p_R, zeta_R를 계산하고 새로운
조건의 분산·검출력까지 예측하는 데 사용한다. 두 점/세 점 적분을 사용하면
큰 poset을 매번 생성하지 않고 이 계수들을 계산할 수 있는지 먼저 평가한다.
수치 적분 오차와 술어 오차는 표본 변동과 별도로 기록한다.

`zeta_R>0`이고 평균 신호가 `c lambda^k`인 경우에 한해, 고정된 오류율에서
단일-poset의 국소 검출 경계가 `lambda_min ∝ N^(-1/(2k))` 형태일 수 있다.
따라서 k=1이면 -1/2, k=2이면 -1/4가 **검증할 조건부 예측**이다.
계수 0, 퇴화한 U-statistic, 비정규 꼬리, 비점근 영역에서는 이 결론을 보류한다.
유한한 N 두 점으로 점근 지수를 확립했다고 쓰지 않는다.

단일-poset 판별의 N과 성능을 측정하는 독립 반복 수 m은 다르다.
m개 poset의 평균을 판별기에 넣어 성능을 올리고 “단일-poset 검출”이라 하지 않는다.

## 5. 실험 설계: 적은 수의 원인을 분리한다

### 5.1 네 관측 프로토콜

| 프로토콜 | 영역의 정의 | 분리하는 문제 |
|---|---|---|
| R+ | 중심을 고정한 slab `(Du,Dv,Dx,Dy)=(1,1,2,6)` | 기존 강한 운영점과 연결 |
| R0 | `(1,1,sqrt(12),sqrt(12))` | 부피 12를 유지하며 transverse 교환 대칭 복원 |
| R- | `(1,1,6,2)` | 같은 부피, focusing/defocusing 축에 대한 영역 방향 교환 |
| D | 같은 중심 관측자의 고유시간 간격으로 정한 on-axis Alexandrov diamond | 임의 직사각형 영역 밖으로 결과가 이어지는지 |

D는 중심 x=y=0에서 `Delta u=1`, `Delta v=-1`인 두 tip을 사용하면
고유시간 간격이 `sqrt(2)`로 고정된다. tip은 표본 N에서 제외한다.
부피는 lambda에 따라 변하며, R들과 같다고 주장하지 않는다.
diamond를 큰 slab로 잘라놓고 같은 영역이라고 부르지 않는다.
관계는 원래 시공간의 인과관계이며, 신호 경로를 관측 박스 안에 가두지 않는다.

주 비교는 **고정 N**으로 하여 원소 수 자체가 곡률 label을 누설하지 않게 한다.
박스들은 부피도 같지만 D는 다르므로 네 영역의 비교를 같은 물리적 밀도 비교라
하지 않는다. `rho=N/V_R(lambda)`를 함께 보고하고, 동일 rho의 Poisson 표본은
이 구분을 확인하는 제한된 보조 실험으로 둔다.

### 5.2 개발 자료와 확인 자료

- 기존 P1–P4·P14 데이터 전체는 개발 자료다. seed를 바꾸었다고
  이미 보고 고른 운영점을 미관측 조건이라고 부르지 않는다.
- 새 파일럿: `N={200,800}`, `lambda={0,1/64,1/16,1/4,1,2}`,
  네 영역, **조건당 최대 m=80**, 총 3,840 poset. 비용 한도와 충돌하면
  실행 전에 설계를 축소하거나 중단한다. 나온 결과에 맞춰 pilot cap을 연장하지 않는다.
- 주 확인: `N={300,1200}`에서 네 영역 각각의 curved 조건 하나와 flat 조건 하나.
  총 8 curved cell + 8 flat cell. 조건당 m=1200을 **가격 산정용 후보**로 둔다.
  최종 m은 G2의 전 과정 검정력 계산 후 확인 자료 생성 전에 동결한다.
- curved lambda 선택 규칙도 파일럿 전에 선언한다. 개발 격자에서 이론 예측이
  **N=300에서** 판별률 약 0.5가 되는 인접 구간을 찾고 기하평균의 lambda를
  각 영역의 후보로 삼는다. **N=1200에서도 같은 lambda를 사용한다.**
  이렇게 해야 N의 효과를 진폭 변경과 혼동하지 않는다.
  0.5를 가로지르는 구간이 없으면 가까운 경계값을 사용하고
  “관측 범위에서 전이 미포착”으로 표시한다. 새 N과 새 lambda에서의 예측을
  검증하되, 기존 N=300 자체를 새로운 밀도라고 표현하지 않는다.
  영역 간 동일 lambda의 비교는 공통 개발 격자에서 제시하고, 서로 다른
  lambda로 선택된 확인 cell의 검출률 차이를 영역 효과만으로 해석하지 않는다.
- 눈으로 확인하지 않은 seed block, classifier, 문장, 신뢰구간, 예외 처리,
  계산 한도, 소스 SHA를 함께 동결한다. 같은 random cloud에서 나온 여러
  lambda나 부분집합은 하나의 cluster이며 분할 경계를 넘지 않는다.

2개 N의 확인점은 **고정 예측의 외부 검증점**이다. 지수 추정 논문으로 바꾸려면
별도 설계에서 최소 4개 N과 충분한 약한 신호 범위를 확보해야 한다.
이번 계획에서 그 확장까지 자동 실행하지 않는다.

### 5.3 비교 대상과 대조군

1. 기존 관계 비율 f의 판별 규칙을 같은 입력·N 조건에서 baseline으로 재현한다.
2. 주 판별기는 영역과 N을 명시한 flat 기준분포의 양측 꼬리 규칙이다.
   nominal false-positive 목표 1%로 보수적으로 설정한다. 곡률 label 없이
   f만 읽지만, **영역·N에 맞춰 보정된 판별기**임을 명시한다.
3. 기존 R+ 기준을 다른 영역에 그대로 적용한 결과도 같은 확인 표본에서 산출한다.
   이 비교는 영역을 모르는 전이가 실패하는지 보는 보조 진단이다.
   영역마다 다시 학습해놓고 영역에 무관한 판별기라고 부르지 않는다.
4. 단순 3-chain 비율을 보조 baseline으로 둔다. marginal 이점과 추가 시간을
   함께 보고한다. 성능이 좋은 통계량을 확인 자료에서 골라 주 결과로 승격하지 않는다.
5. w=0, random-label 평가, index 순열, x/y 교환을 대조한다.
   순열 불변성은 동일 poset에서 정확히 확인한다. 좌표 변환 검사는
   계량·영역·점을 함께 변환한 경우이며 새로운 물리적 회전과 구분한다.
6. 확립된 aniso-a1.0을 새 seed로 재현하는 positive control을 둔다.
   실패하면 새 과학적 결론을 내기 전에 sampler/술어/통계량 결함을 조사한다.
7. paired CRN은 응답 계수의 저분산 진단에만 사용한다. 주 확인의 두 팔은
   독립이며, gained/lost나 두 poset의 점 대응은 판별기 입력에 넣지 않는다.

BD Ricci-scalar 추정기가 Ricci-flat 환경에서 반응하지 않는다는 사실을
그 추정기의 성능 실패나 우리의 우월성으로 주장하지 않는다.
Hasse CJ는 원문의 입력·계산비용을 확인한 뒤 비교 가능할 때만 보조 비교한다.
paired 관측량을 단일-poset 판별기와 같은 문제의 경쟁자로 놓지 않는다.

가장 작은 예측 모형은 위 적분으로 얻은 `p_R, Var(f_N)`와 정규 근사다.
flat 평균의 양옆 `z_0.995 * SD_flat`를 동결 경계로 쓰고, curved 분포에서
그 경계 밖으로 나갈 확률을 beta의 사전 예측으로 계산한다. 곡률값은 예측식에만
들어가고 판별기의 입력에는 들어가지 않는다. 이 정규 근사가 유효하다는 것은
전제가 아니라 G3/G4에서 실패할 수 있는 가설이다.
파일럿 m=80만으로 1% 꼬리의 경험적 quantile을 정밀 보정했다고 주장하지 않는다.
근사가 부적합하여 별도 calibration이 필요하면 확인 전 새 설계와 비용에 포함한다.
확인 표본으로 경계나 분포 모형을 조정하지 않는다. 수치 적분·근사 계산에서 오는
beta 예측 구간의 반폭 목표는 0.01 이하로 두고, G2에서 그 불확실성까지 가격에 넣는다.

## 6. 엄밀성 보완: 같은 코드를 두 번 돌리는 검증을 넘는다

- 폐형식 causal predicate를 독립적인 null-geodesic 경계값 풀이와
  action 적분으로 대조한다. 방사/축상/평탄 극한, 작은 lambda,
  cone에 가까운 쌍, 영역의 모서리를 포함한 사전 지정 검증 집합을 만든다.
  두 계산이 공유하는 유도·library를 밝혀 “독립”의 범위를 명시한다.
- 불확실한 쌍과 diamond membership은 정밀도를 올려 해소하거나 중단한다.
  불확실한 점을 바깥으로 처리하고 새 점을 뽑는 방식은 표본 분포를 바꿀 수 있다.
  임의 제거는 금지한다. 술어·membership의 오차 상한이 목표 통계 오차에
  영향을 주지 않는다는 예산을 파일럿에서 정한다.
- D의 sampler는 실제 부피 측도에 균일함을 증명하고, known flat diamond와
  독립적인 단면 적분으로 검증한다. 기존 volume-form equality를
  diamond-volume equality로 바꾸어 쓰지 않는다.
- p_R, zeta_R, 작은-lambda 계수는 가능한 한 별도의 두 점/세 점 적분 경로로
  확인한다. full-poset 집계를 같은 full-poset 집계로 검산하는 데서 끝내지 않는다.
- 새 증명과 오차 가정은 논문 부록 안에 넣는다. 검토용 명제표에는
  가정 → 유도 → 검증 → 허용되는 문장을 한 줄씩 연결한다.
- 자동화된 교차검증을 외부 물리학자의 심사와 동일시하지 않는다.
  외부 피드백은 유익하지만 교수의 보증이나 유료 검토를 실행 전제조건으로 삼지 않는다.

기존 구현은 재사용한다: `p14_plane_wave.py`의 geometry/predicate,
`p14_probe_p1.py`의 census·axis_volume_ratio·구간 계산,
`p14_probe_p3e.py`의 cluster 처리, `p14_probe_p3c.py`의 평가 도구.
새 코드의 최소 범위는 고정-N/diamond 표본 연결, 새 예측 계산, 확인 runner다.
기존 동결 runner의 상수나 결과 파일을 덮어쓰지 않는다.

## 7. 성공·실패·중단 기준

### 주 확인 문장

주 목표는 “잘 분류했다”보다 **사전에 예측한 성능이 맞았는가**다.
8개 curved cell에서 동결 예측 `beta_hat_j`와 관측 검출률 beta_j를 비교한다.
실용적 정확도는 절대 **10 percentage points** 이내로 제안한다.
이는 미세한 곡률 복원 정밀도가 아니라 검출 가능/어려움/불가용 영역을 구별하는
운영 해상도다. 이 해상도가 연구 질문에 불충분하면 파일럿 전에 더 엄격하게 바꾸고
다시 가격을 계산한다. 데이터를 보고 완화하지 않는다.

| gate | 성공 조건 | 실패 또는 미결일 때 |
|---|---|---|
| G0: 새로움·질문 | 선행연구 및 기존 P3-E와 다른 정량 예측을 명시. 9/21 감사는 좁은 후보만 유지하며 아직 PASS 아님 | 차이가 절차·표본 추가뿐이면 본 캠페인 중단 |
| G1: 응답 유도·수치 건전성 | 먼저 영역별 계수·오차·새 예측을 얻어 G0 재평가. 이어 영역·관측자·수치 규약, 독립 술어/sampler 대조와 대칭성 검사 | 표준 성질의 재유도만 남으면 차별성 부족으로 중단. 구현 실패는 implementation/protocol incident이며 과학적 음성 결과 아님 |
| G2: 실행 가능성 | 동결 오차 예산을 포함한 모든 주 gate의 joint power ≥90%, 계산비용이 한도 내 | 표본 cap보다 필요량이 크면 infeasible; 문턱 완화 없음 |
| G3: false-positive | 8개 flat cell 각각의 상한 ≤5% | 해당 보정법의 타당성을 지지하지 못함 |
| G4: 예측 정확도 | 8개 beta 차이의 전체 CI가 각각 [-0.10,+0.10] 안 | disjoint면 불일치, 겹치지만 포함 안 되면 inconclusive |
| G5: 결과의 가치 | 유도와 예측 검증 또는 해석 가능한 한계가 추가되고, 재현 자료가 완결 | AUC 상승이나 기존 양성 반복만으로 재투고하지 않음 |

G3/G4는 총 16개 비율의 family다. Clopper–Pearson **양측** 구간에
Bonferroni를 적용하여 family coverage를 최소 95%로 한다.
각 구간의 error level은 `0.05/16`, 각 tail은 `0.05/(2*16)`이다.
각 구간이 단순 95%인 것과 “모든 조건에서 95%”를 혼동하지 않는다.
수치 예측의 오차 구간이 있으면 beta의 차이 구간도 그만큼 넓힌다.
G2의 joint power는 G3/G4의 결합 사건에 대한 것이다. 모든 curved cell이
검출률 80%를 넘어야 한다는 결합 주장은 하지 않는다.

“검출 가능”이라고 부를 개별 조건은 같은 구간의 beta 하한 ≥80%와
대응 flat 상한 ≤5%를 모두 요구한다. 모델 검증 G4가 통과해도 beta가 낮으면
그 조건에서는 **검출 불충분을 정확히 예측한 것**이다. 검출점 하나를 사후 선택해
전체 조건의 양성 결론으로 포장하지 않는다.

보조 비교는 별도 표시하며 그 결과로 주 판정을 구제하지 않는다.
null 유의성 검정에서 p>0.05라는 이유로 동등성이나 정보 부재를 선언하지 않는다.
낮은 성능의 CI가 넓으면 “확인되지 않음”이지 “검출 불가능”이 아니다.

## 8. 표본 수와 가격: 지금 계산한 것과 아직 모르는 것

### 8.1 계획용 binomial 계산

실제 새 물리 데이터를 생성하지 않고, 위 구간 판정의 비용만 계산했다.
예를 들어 true FPR=1%, true beta=0.52, 동결 예측=0.50일 때 다음과 같다.
수치적 예측 오차는 이 예시에서 0으로 두었다. 같은 조건의 gate 8쌍에
union bound를 적용한 값이며 전체 설계의 검정력 인증이 아니다.

| m / cell | FPR gate 통과 확률 | 예측 정확도 gate 통과 확률 | 16개 gate의 joint power 하한 |
|---:|---:|---:|---:|
| 400 | 0.949763 | 0.566423 | 0 |
| 800 | 0.999990 | 0.944390 | 0.555040 |
| 1200 | 거의 1 | 0.995761 | 0.966088 |
| 1600 | 거의 1 | 0.999753 | 0.998021 |

따라서 “조건당 수백 개면 충분하다”는 예산부터 정하지 않는다.
**m=1200은 후보일 뿐이다.** G2에서는 pilot의 분산·모델 오차·꼬리 보정 불확실성,
예측 오차의 plausible 범위, 모든 cell을 포함하여 실제 판정 pipeline의 joint
power를 계산한다. Monte Carlo 인증이면 성공률의 exact CP 95% 하한이
90% 이상이어야 한다. 중간 결과에 맞춰 simulation 반복 수도 늘리지 않는다.
break-even 표본 수를 90% power 표본 수처럼 쓰지 않는다.

표를 재계산하는 독립적인 stdlib 예제는 부록 A에 있다. 이는 계획 계산이며
정식 runner를 대신하지 않는다.

### 8.2 계산량과 시간의 한계

`docs/prereg/p14_s1_cost.md`의 과거 같은 host 측정에서 plane-wave 술어는
약 2.11 microseconds/pair, Schwarzschild는 약 768 microseconds/pair였다.
현재 속도로 재측정한 값이 아니며, 아래는 이 값의 단순 환산이다.

- N=300: 약 0.0946 seconds/order.
- N=1200: 약 1.518 seconds/order.
- 확인 16 cell × m=1200 = **19,200 poset**.
  두 N에 절반씩 배분하면 술어 구성요소만 약 **4.30 CPU-hours**다.
- 이것은 end-to-end 비용이 아니다. diamond sampling, 정밀도 승격,
  보조 통계량, 기준분포 보정, 저장, 재현 실행을 더해야 한다.
  P3-E의 N=1200 full-pipeline median 2.624초라는 과거 기록도 있으나
  새 diamond sampler와 동일한 작업이 아니므로 그대로 보증하지 않는다.
- 주 작업은 로컬 CPU로 계획한다. 새 GPU 학습·클라우드·유료 API는 필요하지 않다.
  기존의 10만원은 **게재료 한도**이지 계산비용 사용 허가가 아니다.

제안하는 자원 상한은 **pilot 8 CPU-hours, 확인 전체 48 CPU-hours**다.
하나의 “빠른 실행” 시간 보장이 아니라 실행 전 가격 판정을 위한 제한이다.
calibration 및 sampler 개발까지 포함한 end-to-end 측정과 보수적 외삽이
상한을 넘으면 G2에서 멈춘다. 병렬 코어 수를 늘린 것을 계산량 감소로 쓰지 않는다.
현재 문서는 어떠한 새 캠페인도 실행하지 않았다.

## 부록 A. 표본수 예시 재계산

Python 3.11+ 표준 라이브러리만 사용한다. CP endpoint를 수치적으로 역산하지 않고
양쪽 binomial tail과의 동치로 CI 포함 사건을 계산한다. 아래의 열거는 부동소수점
계산이며, analytic CP 정의와 구별되는 반올림 오차가 있음을 전제로 한다.

```python
from math import exp, fsum, lgamma, log, log1p


def masses(n, p):
    if p == 0:
        return [1.0] + [0.0] * n
    if p == 1:
        return [0.0] * n + [1.0]
    values = [exp(lgamma(n + 1) - lgamma(k + 1) - lgamma(n - k + 1)
                  + k * log(p) + (n - k) * log1p(-p))
              for k in range(n + 1)]
    assert abs(fsum(values) - 1) < 1e-9
    return values


def tails(values):
    cdf, sf = [], []
    total = 0
    for value in values:
        total += value
        cdf.append(total)
    total = 0
    for value in reversed(values):
        total += value
        sf.append(total)
    return cdf, list(reversed(sf))


def gate_power(n, truth, forecast=None):
    tail = 0.05 / 16 / 2
    lower = 0 if forecast is None else max(0, forecast - 0.10)
    upper = 0.05 if forecast is None else min(1, forecast + 0.10)
    cdf, _ = tails(masses(n, upper))
    _, sf = tails(masses(n, lower))
    return fsum(prob for k, prob in enumerate(masses(n, truth))
                if (upper == 1 or cdf[k] <= tail)
                and (lower == 0 or sf[k] <= tail))


assert masses(1, 0.5) == [0.5, 0.5]
assert abs(gate_power(400, 0.52, 0.50) - 0.566423) < 1e-6
for m in (400, 800, 1200, 1600):
    fpr = gate_power(m, 0.01)
    accuracy = gate_power(m, 0.52, 0.50)
    joint_lower = max(0, 1 - 8 * (1 - fpr) - 8 * (1 - accuracy))
    print(m, fpr, accuracy, joint_lower)
```
